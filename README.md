# Move.Learn.Live — інструкція з публікації на GitHub Pages

Ваш сайт готовий. Усі файли в цій папці. Нижче — покрокова інструкція, як викласти його в інтернет за допомогою **безкоштовного хостингу GitHub Pages**.

## Що ви отримаєте

- 8 сторінок (4 українською, 4 польською)
- Автоматичне визначення мови за налаштуваннями браузера + ручний перемикач UA/PL
- Робоча форма зворотного зв'язку (через formsubmit.co — безкоштовна)
- Адаптивний дизайн (працює на телефоні)
- Адреса виду `natalia-potaman.github.io/movelearnlive` (безкоштовно)
- Можливість підключити свій домен `movelearnlive.com` пізніше

## Крок 1. Створіть акаунт на GitHub

Перейдіть на [github.com](https://github.com) і зареєструйтесь. Це безкоштовно.

При реєстрації радив би використати ім'я типу `natalia-potaman` або `natalia-mll` — воно стане частиною адреси сайту.

## Крок 2. Створіть репозиторій

Після входу натисніть зелену кнопку **New** (або плюсик у правому верхньому куті → **New repository**).

Заповніть:
- **Repository name:** `movelearnlive`
- **Description:** Move.Learn.Live website
- Залиште **Public** (для GitHub Pages потрібно публічний)
- Поставте галочку **Add a README file**
- Натисніть **Create repository**

## Крок 3. Завантажте файли

У вашому новому репозиторії натисніть **Add file** → **Upload files**.

Перетягніть **усі файли та папки** з папки `site/` (індекс, папки `ua`, `pl`, `assets`).

Внизу натисніть **Commit changes**.

## Крок 4. Увімкніть GitHub Pages

У вашому репозиторії перейдіть до **Settings** (вгорі праворуч).

У лівому меню знайдіть **Pages**.

В розділі **Source**:
- **Branch:** оберіть `main`
- **Folder:** оберіть `/ (root)`
- Натисніть **Save**

Зачекайте 1-2 хвилини. Зверху з'явиться повідомлення:
> Your site is live at https://natalia-potaman.github.io/movelearnlive/

Відкрийте цю адресу — ваш сайт у мережі.

## Крок 5. Перевірте форму зворотного зв'язку

Форма налаштована через сервіс **formsubmit.co** (безкоштовний).

При першому відправленні з форми ви отримаєте email від formsubmit з посиланням-підтвердженням. Натисніть його — і після цього всі повідомлення з форми йтимуть на `hello@movelearnlive.com`.

**Важливо:** ви маєте мати робочий email `hello@movelearnlive.com`. Якщо його ще немає — створіть тимчасово на gmail (наприклад, `movelearnlive@gmail.com`) і замініть у формах.

Як замінити email у формах:
- Відкрийте файли `ua/contact.html` та `pl/contact.html`
- Знайдіть рядок: `action="https://formsubmit.co/hello@movelearnlive.com"`
- Замініть email на свій

## Крок 6. Підключення власного домену (опційно)

Коли матимете куплений домен `movelearnlive.com`:

1. У налаштуваннях домену (у реєстратора) додайте такі DNS-записи:
   - `A` запис → `185.199.108.153`
   - `A` запис → `185.199.109.153`
   - `A` запис → `185.199.110.153`
   - `A` запис → `185.199.111.153`
   - `CNAME` запис: `www` → `natalia-potaman.github.io`

2. На GitHub: **Settings → Pages → Custom domain** → введіть `movelearnlive.com` → **Save**

3. Зачекайте 24 години для пропагації DNS.

## Як редагувати сайт після публікації

**Простий спосіб (для невеликих правок):**
1. Відкрийте файл прямо на GitHub (наприклад, `ua/index.html`)
2. Натисніть олівець у правому верхньому куті
3. Внесіть зміни в текст
4. Внизу натисніть **Commit changes**
5. Через 1-2 хвилини зміни з'являться на сайті

**Локальне редагування (для серйозних змін):**
1. Завантажте папку проєкту собі на комп'ютер
2. Редагуйте у будь-якому текстовому редакторі (VS Code, Sublime, Notepad++)
3. Завантажте змінені файли назад на GitHub через **Upload files**

## Що додати в майбутньому

Сайт спеціально зроблений простим. Коли захочете розширити, можна додати:

1. **Сторінку Події/Wydarzenia** — список майбутніх подорожей та подій
2. **Блог** — публікації про подорожі, ваші думки, кейси
3. **Галерею** — фото з минулих подій
4. **Інтеграцію з аналітикою** — Google Analytics для відстеження відвідувань
5. **Власний email на домені** — `info@movelearnlive.com`, `natalia@movelearnlive.com`

## Якщо щось не виходить

Найчастіші проблеми та рішення:

- **Сайт не відкривається після Save** — зачекайте ще 5 хвилин. GitHub Pages іноді запускається з затримкою.
- **Зміни не з'являються** — оновіть сторінку з Ctrl+Shift+R (Windows) або Cmd+Shift+R (Mac), щоб скинути кеш.
- **Форма не відправляє** — переконайтеся, що ви натиснули посилання-підтвердження від formsubmit у вашому email.
- **Не працює UA/PL перемикач** — перевірте, що папки `ua` і `pl` завантажилися повністю.
